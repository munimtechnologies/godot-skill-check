# gdcheck 0.3 fixtures

Each block below tests one rule added in gdcheck 0.3. The expected result of every block is in
`expected.json` (run "v03"), written before gdcheck 0.3 was first run against Godot.

A complete script whose last statement is a multi-line lambda. A fenced block has no trailing newline, and
Godot 4.7.2 rejects such a file with "Expected end of file" (godotengine/godot#96228). gdcheck 0.3 adds the
newline, so this block is ok.

```gdscript
extends Node

func _ready() -> void:
    var timer := Timer.new()
    add_child(timer)
    timer.timeout.connect(func():
        print("tick")
    )
```
